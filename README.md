AttendIQ 🎓

Know your limit. Skip wisely.

AttendIQ is a simple, student-friendly attendance calculator built with HTML, CSS, and JavaScript. It helps students track their lecture attendance, calculate attendance percentages, and determine how many lectures they can skip while maintaining the minimum required attendance percentage.

✨ Features

📊 Calculate attendance percentage.

🧮 Calculate how many lectures you can safely skip.

🎯 Set a minimum attendance requirement.


⚡ Fast, lightweight, and easy to use.

🌐 Runs directly in your web browser or you can download the apk for android

🛠️ Built With

HTML5 – Structure

CSS3 – Styling and layout

JavaScript – Attendance calculations and functionality

🚀 Getting Started

Clone this repository:

git clone https://github.com/ABHI45634/AttendIQ.git
